# NEXT.JS QUESTIONS

## 01. What is Next.js?

Next.js is an open-source React framework developed by Vercel that helps developers build production-ready full-stack web applications. It extends React by providing built-in features such as file-based routing, server-side rendering (SSR), static site generation (SSG), API routes, image optimization, and SEO improvements. These features make applications faster, more scalable, and easier to develop compared to using React alone.
